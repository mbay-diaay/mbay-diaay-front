À modifier

Mobile

  • Créer l'écran Connexion (téléphone + mot de passe)
  • Retirer l'écran 02 (code e-mail)
  • Brancher activate et sign-in dans auth_service.dart
  • _doRefresh : déconnecter seulement sur 401
  • Expiration de session : garder PIN et données locales
  • Messages INVALID_ACTIVATION et ACTIVATION_LOCKED
  • Refuser tout rôle autre que technicien
  • Ne pas afficher l'adresse technique tel-…@technicien…local

À décider

  • PIN oublié : aucun parcours prévu
  • Mot de passe oublié : seul le gestionnaire peut régénérer un code
  • Session hors ligne : 7 jours aujourd'hui
  • Compte déjà activé pour la revue Apple
